# feat:データセットアップロード機能とデータ選択機能

## 問題点

- 現在:あらかじめ/data/datasetsにアップロードされたデータをパス参照で指定する必要がある。これめっちゃめんどいしセキュリティ上でもよろしく無い。
- 新規: データセットアップロード機能とデータ選択機能を追加することで、ユーザーが簡単にデータをアップロードし、選択できるようにする。(この機能はサーバtoクライアントという形状のみ適応。クライアント側で動作するアプリケーションの場合は、別途データセットのパスを保存するだけの機能を追加する必要がある。)

## 1. データセットアップロード機能の追加

### バックエンド

#### データセットアップロード用のAPIエンドポイントを作る

SQLの処理は作った。

- GUIから.zip形式でデータセットをアップロードする
- SQLでデータセットのメタ情報を保存する
    - SQLテーブル名: datasets
    - カラム: id(UUID), name(データセットのディレクトリ名), path(データセットの保存先パス), created_at(作成日時), updated_at(更新日時), データセットの形式(VOC, COCO, YOLO, etc.(orininalも可)).
- データセットの保存先は`/data/datasets`ディレクトリとする

- データセットの一覧呼び出しの後選択にすれば、SQLで一個だけを呼び出すなんてことしなくても良くない? Rust(データセット一覧提供)→React(データセット一覧表示&選択)-データセットのパスを送信-> Rust -データセットのパスを流す-> ai-engine(データセットのパスからデータを読み込む)という流れでいいのでは?
