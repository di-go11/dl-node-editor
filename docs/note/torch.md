# torchの忘備録

## 計算グラフ

計算グラフは、深層学習における計算の流れを表す疑似的なグラフ構造のこと。
pytorchでは、以下のような計算の流れを計算グラフとして表現することができる。

1. 順伝播(forward)の計算
2. Lossの計算

## backward

backwardは、計算グラフを逆方向に辿りながら、「微分の連鎖律」を適用して、「各層のパラメータ(重みやバイアス)を、どの方向に、度入れくらい動かせば、最終的なLossが小さくなるのか=「勾配(gradient)」と呼ぶ」を計算する処理のこと。

## シード

- 乱数シードは、疑似乱数生成器(PRNG)の初期状態を決める整数。コンピュータの「乱数」は決定論的な計算で作った数列で、同じシードなら同じ数列が出る(再現性)。

- 「複数シード」=　人が決めた固定値(例: 0,1,2)で学習を複数回行い、乱数の当たり外れの影響を平均±標準偏差で評価すること。実行のたびに乱数でシードを生成するのではなく、シードは実験条件として明示指定し、結果とともに記録する。
- つまり、baselineと提案手法(SelfAttentionやTransformer)で同じシードを使うことで、乱数の当たり外れの影響を排除して、手法の性能差を正しく評価できる。

### シードが関わる箇所

1. 重みの初期化
2. データのシャッフル
3. Dropout・DropPath
4. データ拡張
5. GPUの非決定的演算
