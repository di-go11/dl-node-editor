## 標準ライブラリ

### `std::uniform_int_distribution`

`<random>`にあるクラスで、指定した範囲の整数を同じ確率で一つ選ぶ。

```cpp
#include <random>

std::mt19937_64 rng(seed);                          // 乱数生成器(乱数のもとを作る)
std::uniform_int_distribution<int> dist(0, 10);     // 0〜10 の整数を同じ確率で

int x = dist(rng);                                  // 0, 1, …, 10 のどれか
```

### `std::vector`

#### `std::vector`にはすでに`operator`で専用の演算子が定義されている

|演算子|意味|
|---|---|
|`==`|長さが同じで、全要素が順に`==`ならtrue|
|`!=`|`==`の否定|
|`<``<=``>``>=`|辞書式順序。先頭から比べて、最初に違った要素の大小で決まる。片方がもう片方の先頭部分と一致するなら、短いほうが小さい|
|`<=>`|上の大小比較を 1 つにまとめたもの。C++20 からは < などはこれから作られる|

```cpp
std::vector<int64_t> a{1, 2, 3};
std::vector<int64_t> b{1, 2, 3};
std::vector<int64_t> c{1, 2};

a == b;   // true
a == c;   // false(長さが違う。範囲外は読まない)
c < a;    // true(c は a の先頭部分なので小さい)
```

## 便利なヘッダファイル

### `std::variant`と`template`をつかったOverloadパターンとVisitorパターン

```cpp
template <class... Ts> // ...は可変長テンプレートという。0個以上の型をいくつでも受け取る。typenameでもいい。
struct Overloaded : Ts... // struct Overloaded: A,B,C...
{
    using Ts::operator()...; // 基底のoperator()を全て見えるようにする。
};

// 推論ガイド
template <class... Ts>
Overloaded(Ts...) -> Overloaded<Ts...>; // Overloaded(型Ts...の引数)のように書かれたら、その型はOverloaded<Ts...>と推論する。という宣言。
```

- operator()の基底クラスを継承して、スコープ上で見えるようにする。

```cpp
template <class... Ts> // ...は可変長テンプレートという。0個以上の型をいくつでも受け取る。typenameでもいい。
struct Overloaded : Ts... // struct Overloaded: A,B,C... ラムダ関数を基底クラスとして継承する。
{
    using Ts::operator()...; // 基底のoperator()を全て見えるようにする。
};
```

1. Overloadedは基底クラスのラムダ関数を全て継承する。
2. `using Ts::operator()...;`でOperatorが見えるようになり、引数の型で処理を選べる。


- 型推論を可能にする。

```cpp
template <class... Ts>
Overloaded(Ts...) -> Overloaded<Ts...>; // Overloaded(型Ts...の引数)のように書かれたら、その型はOverloaded<Ts...>と推論する。という宣言。
```

### `ostream`,`ostringstream`,`ofstream`

```tree
std::ostream            … 「<< で書き出せるもの」の共通の型
 ├ std::cout             … 画面(標準出力)に書く
 ├ std::ofstream         … ファイルに書く
 └ std::ostringstream    … 内部の文字列に書く → .str() で取り出す
 ```

※注意:`ostream`はコピーコンストラクタが禁止されているため、関数などで値で返そうとするとエラーになる。

#### `ostringstream`

書き出し先が画面ではなく文字列になっている`ostream`.`to_string()`では整数型実引数の型が数値のときにしか使えないがこれなら、多くの型を文字列に変換できる。また、`str()`を使うことで、`std::string`に変換可能。


### operator

#### 演算子のオーバーロード

`operator`を使うことで、自分で作った型に対して演算子の意味を定義できる。

書き方はこんな感じ`operator<演算子>()`

```cpp
struct Vec2
{
    double x, y;
};

Vec2 operator+(const Vec2 &a, const Vec2 &b)
{
    return {a.x + b.x, a.y + b.y};
}

bool operator==(const Vec2 &a, const Vec2 &b)
{
    return a.x == b.x && a.y == b.y;
}

// 使う側
Vec2 p{1, 2}, q{3, 4};
Vec2 r = p + q;   // operator+(p, q) が呼ばれる → {4, 6}
```

定義できるものとできないものはこんな感じ

||内容|
|---|---|
|定義できる|+ - * / == < << [] () += ++ など、ほとんどの演算子|
|定義できない|. :: ?: sizeof など、ごく一部の演算子|

また、新しい演算子を作ることはできない。
