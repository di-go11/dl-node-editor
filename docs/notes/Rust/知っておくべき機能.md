# 知っておくべき機能

## FROM

### `From`を実装すると標準ライブラリ`Into`が自動で実装される。

```rust
// std の中に、こういう汎用の実装(ブランケット実装)が書かれている
impl<T, U> Into<U> for T
where
    U: From<T>,
{
    fn into(self) -> U {
        U::from(self)
    }
}

```

逆向きはなし
