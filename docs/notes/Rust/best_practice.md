# rustのベストプラクティス

## 構造体のフィールドの取り扱い

|状況|書き方|このプロジェクトでの例|
|---|---|---|
|ただのデータの入れ物で、どんな値でもよい|pub フィールド。ゲッターもセッターも書かない|HttpConfig、API のリクエスト/レスポンス DTO|
|値にルールがある(空文字は不可、0 より大きい、など)|非公開フィールド + 検証付きの new() + 必要ならゲッター|DatasetId(as_str() で読むだけ)|
|外から触らせる必要がない|非公開フィールド。アクセサも書かない|FileDatasetSaver の dataset_root|

値を詰めて渡すだけなら、pubフィールドで十分, ルールを型で保証したい場合はnewを使う。
